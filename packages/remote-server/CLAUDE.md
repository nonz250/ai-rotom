# packages/remote-server/

mcp-server の core をリモート MCP サーバーとして動かす。既定のデプロイ先は Cloudflare Workers で、npm には公開しない。

## サービスへの依存を `platforms/` に閉じる

`handler.ts` と `config.ts` は Web 標準の `Request` と `Response` だけを使う。サービス固有の API や型は `platforms/<サービス>.ts` の外に持ち込まない。handler や config に入れると、他のサービスで動かすときに作り直しになる。

`tsconfig.json` は Node の型を読まず、`WebWorker` の lib だけで型検査する。`Buffer` や `process` のような Workers にないグローバルを型検査で弾くためで、`types: ["node"]` を足さない。

## 認証

- `AUTH_TOKEN` が未設定か 32 文字に満たなければ、すべてのリクエストを拒否する。共有トークン 1 つで守っているので、推測できる短い値で公開されるよりは止める
- トークンは SHA-256 のダイジェスト同士で比べる。長さの違いで早く返すと、応答時間から長さが漏れる。Workers の `crypto.subtle.timingSafeEqual` は他のサービスにないので使わない
- 認証を通ったら、`authorization` ヘッダーを除き、パスを `/mcp` に戻してから SDK に渡す。SDK は URL とヘッダーをツールの処理まで渡すので、トークンをそこへ広げない

## 認証より前に拒否するもの

- `Origin` ヘッダーが付いたリクエストは、値によらず 403 で拒否する。`Origin: null` も含む。ブラウザには対応しないので、許可する Origin の設定は持たない
- `ALLOWED_HOSTS` を設定したときだけ、ホスト名を確かめる。workers.dev のサブドメインはアカウントごとに違い、既定値を置けないため
- ホスト名は `Host` ヘッダーではなく `new URL(request.url).hostname` で比べる。手前で TLS を外すプロキシの後ろでは `Host` が内側の名前になりうるので、https の確認と同じく、クライアントから見た URL を渡してもらう前提にそろえる

## リクエスト数の制限

- 認証を通ったあとにだけ数える。認証前に数えると、でたらめなトークンを送るたびに別のキーができて制限にならない。認証前のリクエストが枠を消費することは受け入れている
- キーはトークンの SHA-256 ダイジェストの先頭から作り、トークンそのものを含めない。キーは制限の仕組みの側に保存されるため
- Cloudflare の Rate Limiting バインディングは数え直すまでの秒数を返さない。`wrangler.toml` の `period` を変えたら `cloudflare.ts` の `RATE_LIMIT_PERIOD_SECONDS` も合わせる

## 本文

本文はハンドラーで読み、配列で届く JSON-RPC のバッチを 400 で拒否してから、パース済みの値を SDK に渡す。バッチは 1 リクエストで最大 100 件を処理させられ、CPU 時間の上限と噛み合わない。パース済みの値を渡すと SDK の `maxRequestBodySize` は効かないので、本文の上限はハンドラーで確かめる。

## Workers の制約

- リクエストごとにサーバーとトランスポートを作り直す。セッションを持たないので、GET と DELETE は 405 を返す
- `nodejs_compat` は有効にしない。有効にすると、保存系のような Node の組み込みモジュールを使うコードが core に混ざっても気付けなくなる。wrangler はそれを外部参照のままバンドルして失敗しないので、`scripts/verify-worker-bundle.sh` で検出している。これは回帰チェックで、悪意あるコードを見つけるものではない
- 無料プランの CPU 上限は 1 リクエスト 10 ms。データの Map はモジュール読み込み時に 1 回だけ作る
- 習得技すべての計算は 10 ms を超えるので、全技系ツールの自分側は既定で moves を必須にしている。`REQUIRE_MOVES` が `"false"` のときだけ任意にし、読み違えで必須が外れないようにする。相手側は必須にしない。技構成がわからない相手の型を AI に作らせることになるため。instructions で案内するだけでは AI クライアントが従わなかったので、ツール側でエラーにしている
