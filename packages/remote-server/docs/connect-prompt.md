# ai-rotom のリモート MCP サーバーにつなぐ

このファイルは、AI エージェントに読ませるための手順書です。読んだエージェントは、利用者のクライアントに ai-rotom のリモート MCP サーバーを登録し、つながったことを確かめてください。

ai-rotom は、ポケモンチャンピオンズの種族値・技・タイプ相性の確認やダメージ計算に使う MCP サーバーです。

## つなぐ先

次の URL に Streamable HTTP でつなぎます。認証はいりません。サーバーの名前は `ai-rotom` にしてください。

```
https://ai-rotom.nonz250.workers.dev/mcp
```

## 進め方

1. 自分がどのクライアントで動いているかを確かめます。わからなければ利用者に聞いてください。
2. 下にある、そのクライアントの手順で登録します。コマンドを実行できるなら自分で実行します。設定画面での操作が要るなら、利用者に操作を 1 つずつ伝えます。
3. `ai-rotom` という名前のサーバーが既に登録されていたら、置き換えてよいかを利用者に確かめてから進めます。手元で動かす stdio 版を同じ名前で登録していることがあります。
4. 登録できたら、最後の「つながったかを確かめる」の手順で確かめます。

## クライアントごとの登録の手順

### Claude Code

先に `claude mcp get ai-rotom` で、同じ名前の登録がないかを確かめます。あれば、どの scope に登録されているかを見て、利用者の了承を得てから `claude mcp remove ai-rotom -s <scope>` で外します。残したまま別の scope に足すと、Claude Code は local、project、user の順に優先するので、古い登録が使われ続けることがあります。

次のコマンドで登録します。特定のプロジェクトだけで使うと言われていなければ、どのプロジェクトからも使えるように `--scope user` を付けます。

```bash
claude mcp add --scope user --transport http ai-rotom https://ai-rotom.nonz250.workers.dev/mcp
```

`claude mcp list` を実行し、`ai-rotom` が上の URL でつながっていると表示されることを確かめます。今のセッションでツールが見えないときは、Claude Code を開き直すよう利用者に伝えます。

### Codex

CLI、アプリ、IDE の拡張機能は同じ設定を読むので、どれから登録しても同じです。先に `codex mcp get ai-rotom` で同じ名前の登録がないかを確かめ、あれば利用者の了承を得てから `codex mcp remove ai-rotom` で外します。次のコマンドで登録します。

```bash
codex mcp add ai-rotom --url https://ai-rotom.nonz250.workers.dev/mcp
```

コマンドを実行できないときは、`~/.codex/config.toml` に次を書き足すよう利用者に伝えます。

```toml
[mcp_servers.ai-rotom]
url = "https://ai-rotom.nonz250.workers.dev/mcp"
```

`codex mcp list` で `ai-rotom` が上の URL で表示されることを確かめます。今のセッションでツールが見えないときは、Codex を開き直すよう利用者に伝えます。

### claude.ai と Claude Desktop

チャットからは設定を変えられないので、利用者に次の操作を伝えます。

1. 設定のコネクタの画面を開き、カスタムコネクタを追加します
2. 名前に `ai-rotom`、リモート MCP サーバーの URL に上の URL を入れます。OAuth の欄は空のままにします
3. 追加したら、チャットの画面でコネクタの `ai-rotom` を有効にします

### Muse やそのほかのクライアント

カスタムコネクタやリモート MCP サーバーを追加する設定に、名前と URL を入れるよう利用者に伝えます。トランスポートを選ぶ欄があれば Streamable HTTP を選びます。HTTP とだけ書かれていることもあります。認証の欄があれば「なし」にします。

画面の名前や場所がわからないときは、推測で案内せず、クライアントのヘルプでカスタムコネクタやリモート MCP サーバーの追加方法を調べるよう利用者に伝えます。

## つながったかを確かめる

ai-rotom のツールが見えるようになったら、`get_pokemon_info` に `ガブリアス` を渡して 1 回呼び、種族値やタイプが返ることを確かめます。返ってきたら、つながったことを利用者に伝えて終わります。

## うまくいかないとき

状態コードだけでなく、応答の本文も読んで見分けます。

- 403 で本文が `Requests from browsers are not supported` なら、ブラウザから直接つなぐクライアントです。このサーバーはブラウザからの接続を受け付けません
- 403 で本文が `HTTPS is required` なら、URL が `http://` になっています。`https://` に直します
- 404 なら、URL が違います。末尾が `/mcp` で終わっているかを確かめます
- 401 なら、クライアントが認証を求める設定になっています。認証や OAuth の欄を空にするか「なし」にします
- 405 なら、クライアントが古い SSE のトランスポートでつないでいます。Streamable HTTP に変えます
- 429 で本文が `Too Many Requests` なら、接続元ごとの 60 秒あたりのリクエスト数の上限を超えています。1 分ほど待ってからやり直します
- 429 でも、Cloudflare のエラーページが返り error 1027 と書かれていれば、無料の枠の 1 日の上限に達しています。日本時間の 9 時に枠が戻るまで使えないことを利用者に伝えます
- 503 で本文が `Client address is unavailable` なら、サーバー側で接続元がわからず受け付けられていません。利用者の側では直せないので、時間をおいてやり直すよう伝えます

claude.ai や Muse のように、クライアントの会社のサーバーからつなぐクライアントでは、同じクライアントの利用者がまとめて 1 つの接続元として数えられます。待っても 429 が続くときは、ほかの利用者と枠を分け合っていることを利用者に伝えます。

## リモート版でできないこと

利用者に聞かれたら伝えてください。

- `save_party` などのパーティ保存系のツールは使えません。パーティは分析ツールに毎回引数で渡します
- 全技ダメ計・6v6 ダメ計・対面分析・選出分析では、自分側のポケモンの技構成の指定が必須です。相手側は省略できます
- 接続元ごとに、60 秒あたりのリクエスト数に上限があります。超えると、しばらく待つよう求めるエラーを返します
- ブラウザから直接つなぐクライアントには対応していません
- 無料の枠で動かしているので、1 日の利用が多いと、その日のうちは使えなくなることがあります
