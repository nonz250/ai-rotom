# ai-rotom のリモート MCP サーバーにつなぐ

このファイルは、AI エージェントに読ませるための手順書です。読んだエージェントは、利用者のクライアントに ai-rotom のリモート MCP サーバーを登録し、つながったことを確かめてください。

ai-rotom は、ポケモンチャンピオンズの種族値・技・タイプ相性の確認やダメージ計算に使う MCP サーバーです。

## つなぐ先

次の URL に Streamable HTTP でつなぎます。認証はいりません。サーバーの名前は `ai-rotom` にしてください。

```
https://ai-rotom.nonz250.workers.dev/mcp
```

## 進め方

1. 自分がどのクライアントで動いているかを確かめます。わからなければ利用者に聞いてください。
2. 下にある、そのクライアントの手順で登録します。コマンドを実行できるなら自分で実行します。設定画面での操作が要るなら、利用者に操作を 1 つずつ伝えます。
3. `ai-rotom` という名前のサーバーが既に登録されていたら、置き換えてよいかを利用者に確かめてから進めます。手元で動かす stdio 版を同じ名前で登録していることがあります。
4. 登録できたら、最後の「つながったかを確かめる」の手順で確かめます。

## クライアントごとの登録の手順

### Claude Code

次のコマンドで登録します。特定のプロジェクトだけで使うと言われていなければ、どのプロジェクトからも使えるように `--scope user` を付けます。

```bash
claude mcp add --scope user --transport http ai-rotom https://ai-rotom.nonz250.workers.dev/mcp
```

`claude mcp list` を実行し、`ai-rotom` がつながっていると表示されることを確かめます。今のセッションでツールが見えないときは、Claude Code を開き直すよう利用者に伝えます。

### Codex

CLI、アプリ、IDE の拡張機能は同じ設定を読むので、どれから登録しても同じです。次のコマンドで登録します。

```bash
codex mcp add ai-rotom --url https://ai-rotom.nonz250.workers.dev/mcp
```

コマンドを実行できないときは、`~/.codex/config.toml` に次を書き足すよう利用者に伝えます。

```toml
[mcp_servers.ai-rotom]
url = "https://ai-rotom.nonz250.workers.dev/mcp"
```

`codex mcp list` で `ai-rotom` が表示されることを確かめます。今のセッションでツールが見えないときは、Codex を開き直すよう利用者に伝えます。

### Claude のアプリ（claude.ai、Claude Desktop）

チャットからは設定を変えられないので、利用者に次の操作を伝えます。

1. 設定のコネクタの画面を開き、カスタムコネクタを追加する
2. 名前に `ai-rotom`、リモート MCP サーバーの URL に上の URL を入れる。OAuth の欄は空のままにする
3. 追加したら、チャットの画面でコネクタの `ai-rotom` を有効にする

### Muse やそのほかのクライアント

カスタムコネクタやリモート MCP サーバーを追加する設定に、名前と URL を入れるよう利用者に伝えます。トランスポートを選ぶ欄があれば Streamable HTTP（HTTP）を選び、認証の欄があれば「なし」にします。

画面の名前や場所がわからないときは、推測で案内せず、クライアントのヘルプでカスタムコネクタやリモート MCP サーバーの追加方法を調べるよう利用者に伝えます。

## つながったかを確かめる

ai-rotom のツールが見えるようになったら、`get_pokemon_info` に `ガブリアス` を渡して 1 回呼び、種族値やタイプが返ることを確かめます。返ってきたら、つながったことを利用者に伝えて終わります。

## うまくいかないとき

- 403 が返るときは、ブラウザから直接つなぐクライアントです。このサーバーはブラウザからの接続を受け付けません
- 401 や 404 が返るときは、URL が違います。末尾が `/mcp` で終わっているかを確かめます
- 429 が返るときは、接続元ごとの 60 秒あたりのリクエスト数の上限を超えています。少し待ってからやり直します
- どのリクエストもエラーになるときは、無料の枠の 1 日の上限に達していることがあります。日本時間の 9 時に枠が戻ります

## リモート版でできないこと

利用者に聞かれたら伝えてください。

- `save_party` などのパーティ保存系のツールはありません。パーティは分析ツールに毎回引数で渡します
- 全技ダメ計・6v6 ダメ計・対面分析・選出分析では、自分側のポケモンの技構成の指定が必須です
