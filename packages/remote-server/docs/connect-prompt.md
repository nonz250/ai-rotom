# ai-rotom のリモート MCP サーバーにつなぐ

このファイルは、ChatGPT、Claude、Gemini、Muse などのチャットのアプリや web 版に貼り付けて読ませるための手順書です。読んだ AI は、利用者が ai-rotom のリモート MCP サーバーをコネクタとして追加し、使えるようになるまでを案内してください。

ai-rotom は、ポケモンチャンピオンズの種族値・技・タイプ相性の確認やダメージ計算に使う MCP サーバーです。

## つなぐ先

次の URL に Streamable HTTP でつなぎます。認証はいりません。コネクタの名前は `ai-rotom` にしてください。

```
https://ai-rotom.nonz250.workers.dev/mcp
```

## 進め方

チャットの中からはアプリの設定を変えられないので、利用者に操作を 1 つずつ伝え、終わるたびに結果を聞いてから次へ進みます。

1. 自分がどのアプリで動いているかを確かめます。わからなければ利用者に聞いてください。
2. そのアプリに、リモート MCP サーバーをコネクタとして追加する機能があるかを確かめます。ない場合は、このアプリからは ai-rotom を使えないことを利用者に伝えて終わります。
3. 下の「追加するときに入れる値」を、アプリの画面に合わせて案内します。
4. 追加できたら、最後の「使えるようになったかを確かめる」の手順で確かめます。

画面の名前や場所は、アプリの更新で変わります。わからないときや、利用者の画面が案内と違うときは、推測で案内しないでください。アプリのヘルプで「カスタムコネクタ」や「リモート MCP サーバー」の追加方法を調べるよう利用者に伝えます。調べられるなら、自分で公式のヘルプを調べてから案内します。

## 追加するときに入れる値

コネクタの追加は、多くのアプリで設定のコネクタやアプリの画面にあります。プランや、開発者向けの機能を有効にしているかによって、追加の機能が出てこないことがあります。スマートフォンのアプリでは追加できず、web 版で追加することもあります。

- 名前は `ai-rotom` にします
- URL には上の URL をそのまま入れます。末尾の `/mcp` を落とさないようにします
- 認証を選ぶ欄があれば「なし」にします。OAuth の欄は空のままにします
- トランスポートを選ぶ欄があれば Streamable HTTP を選びます。HTTP とだけ書かれていることもあります。SSE は選びません
- 追加したあと、チャットの画面でコネクタを有効にする操作が要るアプリもあります

## 使えるようになったかを確かめる

追加したコネクタは、今のチャットでは使えないことがあります。新しいチャットを開いて `ai-rotom` のコネクタを有効にし、「ai-rotom でガブリアスの種族値を調べて」と頼んでもらいます。種族値やタイプが返ってきたら、つながっています。

## うまくいかないとき

追加の画面やチャットにエラーが出たら、表示された文面を利用者に教えてもらい、次で見分けます。

- `Requests from browsers are not supported` なら、ブラウザから直接つなぐアプリです。このサーバーはブラウザからの接続を受け付けないので、このアプリからは使えません
- `HTTPS is required` なら、URL が `http://` になっています。`https://` に直します
- 404 や `Not Found` なら、URL が違います。末尾が `/mcp` で終わっているかを確かめます
- 401 や認証のエラーなら、アプリが認証を求める設定になっています。認証を「なし」にし、OAuth の欄を空にします
- 405 なら、古い SSE のトランスポートでつないでいます。Streamable HTTP に変えます
- `Too Many Requests` なら、60 秒あたりのリクエスト数の上限を超えています。1 分ほど待ってからやり直します
- Cloudflare のエラーページに error 1027 と書かれていれば、無料の枠の 1 日の上限に達しています。日本時間の 9 時に枠が戻るまで使えないことを伝えます
- `Client address is unavailable` なら、サーバー側で接続元がわからず受け付けられていません。利用者の側では直せないので、時間をおいてやり直すよう伝えます

チャットのアプリは、アプリの会社のサーバーからつなぐので、同じアプリの利用者がまとめて 1 つの接続元として数えられます。待っても `Too Many Requests` が続くときは、ほかの利用者と枠を分け合っていることを伝えます。

## 気をつけること

利用者に聞かれたら伝えてください。無料で公開しているサーバーなので、次の制限があります。

- パーティを保存しておく機能は使えません。分析を頼むたびに、パーティのポケモンを伝えてもらいます
- ダメージ計算や選出の分析の一部では、自分のポケモンの技を伝えてもらう必要があります。相手のポケモンの技は伝えなくても大丈夫です
- 短い時間にたくさん使うと、しばらく待つよう求められます。この上限は、同じアプリを使っている人全員で分け合っています
- 1 日の利用が多いと、その日のうちは使えなくなることがあります。日本時間の 9 時に使えるようになります
