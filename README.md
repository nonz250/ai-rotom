# ai-rotom

ポケモンチャンピオンズの対戦アドバイザーです。

ChatGPT や Claude などのチャットのアプリに追加すると、AI が ai-rotom のデータを調べながら、種族値・技データ・タイプ相性の確認、ダメージ計算、パーティ分析、選出の相談に答えるようになります。Claude Code や Codex などの AI エージェントからも使えます。

- ダメージ計算を、1 対 1 の単発・全技・6v6 の 3 つの粒度で行えます
- パーティの弱点や攻撃範囲、2 つのパーティの違いを分析できます
- 対面や選出の判断に使うデータをまとめて取り出せます。最終的な判断は AI が行います
- 入力は日本語でも英語でも受け付けます

## 使用例

AI クライアントに以下のように聞くと、内部でツールが自動で呼ばれます。

> 「カバルドンの対策候補を教えて」

e.g.) `search_pokemon_by_type_effectiveness` でカバルドンの弱点タイプ（みず/くさ/こおり）の攻撃技を覚えるポケモンが検索され、AI が選んだ候補ごとに `analyze_matchup` で双方向のダメ計・素早さ比較・先制技が取得されます。受け型か速攻型かといった対策方針の判断は AI が行います。必要に応じてカバルドンの技構成や行動をプロンプトに入力し、あくび受けループに対する対策の検討をしてください。

> 「リザードン、ギャラドス、ピカチュウの 3 体パーティに足りないタイプ耐性は？」

e.g.) `analyze_party_weakness` が呼ばれ、各タイプを弱点に持つメンバー数（`teamWeaknesses`）と抜群を取れないタイプ（`uncoveredTypes`）を返します。致命性の判断は AI が文脈で行います。

## チャットのアプリで使う

ChatGPT、Claude、Gemini、Muse などのチャットのアプリや web 版から、インストールなしで使えます。アプリに ai-rotom を「コネクタ」として追加すると、チャットでポケモンのことを聞いたときに、AI が ai-rotom のデータを調べて答えるようになります。

### AI に追加の手順を聞く

使いたいアプリのチャットに、次の文章をそのまま貼り付けて送ってください。AI が、そのアプリでの追加の手順を 1 つずつ案内します。

```
次の手順書を読んで、このアプリに ai-rotom を追加する方法を案内してください。
https://raw.githubusercontent.com/nonz250/ai-rotom/main/packages/remote-server/docs/connect-prompt.md
```

AI が URL を開けないと答えたときは、[手順書](./packages/remote-server/docs/connect-prompt.md)の中身をコピーして貼り付けてください。

### 自分で追加する

アプリの設定にある「コネクタ」や「カスタムコネクタ」の画面から、次の内容で追加します。画面の場所はアプリによって違います。

- 名前は `ai-rotom`
- URL は `https://ai-rotom.nonz250.workers.dev/mcp`。末尾の `/mcp` まで入れます
- 認証は「なし」
- 通信方式を選ぶ欄があれば「Streamable HTTP」か「HTTP」を選びます。「SSE」は選びません

アプリやプランによっては、コネクタを追加できないことがあります。

### 気をつけること

無料で公開しているサーバーなので、次の制限があります。

- パーティを保存しておく機能と、テキストからパーティを取り込む機能は使えません。分析を頼むたびに、パーティのポケモンを伝えてください
- ダメージ計算や選出の分析の一部では、自分のポケモンの技を伝える必要があります。相手のポケモンの技は伝えなくても大丈夫です
- 短い時間にたくさん使うと、しばらく待つよう求められます。この上限は、同じアプリを使っている人全員で分け合っています
- 1 日の利用が全体で多いと、上限に達して、次の日本時間 9 時まで使えなくなることがあります

## Claude Code や Codex で使う

コマンドラインで動く AI エージェントでは、ai-rotom を手元のパソコンで動かして使えます。パーティの保存を含め、すべての機能を制限なしで使えます。Node.js 24 以上が必要です。

### Claude Code

```bash
claude mcp add ai-rotom -- npx -y @nonz250/ai-rotom
```

### Codex

```bash
codex mcp add ai-rotom -- npx -y @nonz250/ai-rotom
```

### ほかの MCP クライアント

次のコマンドを、標準入出力でつなぐ MCP サーバーとして登録します。

```bash
npx -y @nonz250/ai-rotom
```

### 公開しているサーバーにつなぐ

手元で動かさずに、チャットのアプリと同じ公開サーバーにつなぐこともできます。使えない機能と 1 日の上限は「[気をつけること](#気をつけること)」と同じです。リクエスト数は、接続元のアドレスごとに 60 秒あたり 60 件までです。ブラウザの中で動く MCP クライアントからはつなげません。

```bash
claude mcp add --transport http ai-rotom https://ai-rotom.nonz250.workers.dev/mcp
codex mcp add ai-rotom --url https://ai-rotom.nonz250.workers.dev/mcp
```

公開サーバーと同じものを自分の Cloudflare アカウントに立てる方法は、[packages/remote-server/README.md](./packages/remote-server/README.md) にまとめています。

## 利用可能な MCP ツール

プロンプトに入力する言語は日本語・英語どちらでも可能です。

### 情報取得系

| ツール | 概要 |
|---|---|
| `get_pokemon_info` | ポケモンの基本情報（種族値・タイプ・特性） |
| `get_pokemon_summary` | ポケモンの総合プロファイル（防御相性・覚える技の集計・実数値） |
| `get_move_info` | 技の情報 |
| `get_ability_info` | 特性の情報 |
| `get_item_info` | 持ち物の情報 |
| `get_nature_info` | 性格の plus/minus |
| `get_type_info` | タイプ相性（攻撃時・受け時） |
| `get_condition_info` | 天候/フィールド/状態異常/壁 |
| `get_learnset` | 覚える技一覧 |

### 検索系

| ツール | 概要 |
|---|---|
| `search_pokemon` | タイプ・種族値条件で検索 |
| `search_pokemon_by_move` | 技を覚えるポケモン逆引き |
| `search_pokemon_by_ability` | 特性を持つポケモン逆引き |
| `search_pokemon_by_type_effectiveness` | タイプ相性条件で逆引き |

### 計算系

| ツール | 概要 |
|---|---|
| `calculate_stats` | 実数値計算 |
| `calculate_damage_single` | 1 対 1 の 1 技ダメ計 |
| `calculate_damage_all_moves` | 1 対 1 の全技ダメ計 |
| `calculate_damage_party_matchup` | 6v6 ダメ計 |
| `list_speed_tiers` | 素早さライン一覧 |
| `analyze_damage_range` | ダメ計＋耐久逆計算（最小 SP 配分探索） |

### 分析系

| ツール | 概要 |
|---|---|
| `analyze_matchup` | 2 体対面分析 |
| `analyze_party_weakness` | パーティ弱点分析 |
| `analyze_party_coverage` | パーティ攻撃カバレッジ分析 |
| `analyze_selection` | 6v6 選出判断一括分析 |
| `compare_parties` | 2 つのパーティの統計差分（メンバー・タイプ・弱点・カバレッジ・素早さ・種族値合計） |

### パーティ永続化

自分のパーティ構築を `~/.ai-rotom/parties.json` に保存し、セッションをまたいで再利用できる。

| ツール | 概要 |
|---|---|
| `save_party` | パーティを保存 (同名は上書き) |
| `load_party` | 保存済みパーティを 1 件取得 |
| `list_parties` | 保存済みパーティのサマリ一覧 |
| `delete_party` | 保存済みパーティを削除 |
| `import_party_from_text` | ポケソル形式のテキストからパーティを取り込んで保存 |

## トラブルシューティング

### 入力エラー: 「ポケモン「XXX」が見つかりません」

- 日本語名の表記ゆれ（半角/全角）が原因の可能性があります
- エラーメッセージに表示される類似候補を参考にしてください
- フォルム違い（例: メガリザードンX / Y）は正式名称で指定してください

### 「能力ポイント(SP)は各ステータス 32 以下です」

- 従来の EV（252 等）を渡していないか確認してください
- ポケモンチャンピオンズ仕様では **各ステ 0-32 / 合計 0-66** です
